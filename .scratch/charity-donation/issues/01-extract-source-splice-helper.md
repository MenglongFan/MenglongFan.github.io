# 01: 抽出源码切片测试助手

**What to build:** 让「把未导出的函数从源码里切出来测试」这件事只写一次。现在每个纯函数测试都要自己复述一遍锚点字符串和切片逻辑，锚点一改就得同时改几处，漏一处就是静默失效——测试还在跑、但测的已经不是那段代码了。抽出一个共用的助手之后，新增一个纯函数测试只需要声明「切哪一段、要哪个函数」。这是为后面的捐赠称谓测试铺路，本身不改变任何生产代码的行为。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 既有罚金算法测试改用助手后行为完全不变：同样的用例、同样的通过结论、同样的失败输出
- [ ] 助手在锚点缺失或顺序颠倒时报错退出，绝不静默跳过
- [ ] 助手只依赖 Node 内置模块，不引入测试框架、不新增依赖
- [ ] 新增一个纯函数测试时不需要复制任何切片代码
- [ ] 以 `node <测试文件>` 直接运行仍然可用，不需要额外的运行器或配置
