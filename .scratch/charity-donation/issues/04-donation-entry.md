# 04: 录入一笔慈善捐赠

**What to build:** 房主在奖池页点「录入捐赠」，从花名册里选捐赠人（带头像、单选、再点一次取消选择），填金额（最多两位小数），可以附一句备注（选填）。提交后奖池余额、慈善榜、流水三处同时更新，并提示「已记录 · 累计 X 元 · 称谓」，省得再翻一遍榜单确认。捐赠是账务操作，开放录入等于任何人可以伪造一笔入账并给自己发称谓，所以整个动作需要房主密码。

**Blocked by:** 02

**Status:** ready-for-agent

- [ ] 录入需要房主密码，未带密码被拒
- [ ] 捐赠人必填且必须存在于花名册；不存在或缺失时被拒，并给出看得懂的报错
- [ ] 金额必须大于 0，否则被拒
- [ ] 金额最多两位小数，三位以上被拒（金额会累加进余额链，三位小数会让链上每个数字都变脏）
- [ ] 备注可以为空；留空时页面上不出现一个空的备注位
- [ ] 捐赠不绑定赛季，不影响任何赛季的结算
- [ ] 录入后新余额 = 录入前余额 + 金额
- [ ] 录入后慈善榜、余额拆分行、账单三处同时反映新数据，无需手动刷新
- [ ] 提交成功后的提示包含该玩家新的累计额与对应称谓
- [ ] 捐赠人选择器支持再点一次取消选择，点错不用刷新页面
- [ ] 选人复用「赛季 → 选参赛者」那套选择器，不引入下拉框
