# 07: 沙盒端到端验证

**What to build:** 在本地沙盒（本地后端 + 本地数据库，前端指向本地）里把整条路走一遍：连续录入 3 笔（其中一笔跨过称谓档位）→ 看慈善榜与余额 → 删掉中间那一笔 → 余额链逐行自洽 → 账单正确。这一票专门覆盖**不属于任何单个切片**的一致性断言——单张票各自绿，合起来账目仍然可能错。验证只对本地沙盒库执行，绝不碰线上数据。

**Blocked by:** 03、05、06

**Status:** ready-for-agent

- [ ] 走完整旅程：录 3 笔（含一笔跨档位）→ 慈善榜与余额正确 → 删中间一笔 → 余额链逐行自洽 → 账单正确
- [ ] 整段旅程中「贡献榜」完全不变（捐赠不污染罚金统计）
- [ ] 捐赠不出现在任何赛季的结算里，也不影响赛季状态机
- [ ] 累积多笔后，累计额与总额都不出现浮点尾数（收口到分）
- [ ] 删除导致的掉档回退在端到端路径上真实发生一次，而不只是在单测里
- [ ] 窄屏（390 宽）下慈善榜、余额拆分行、录入弹窗、捐赠记录弹窗都不溢出
- [ ] 全程页面不出现滚动条（本项目既有约束）
- [ ] 验证前后本地库可回滚到初始状态，不留脏数据
- [ ] 数字类断言与接口返回比对，**不**断言 DOM 文本（榜单与余额用 rAF 计数动画渲染，无头浏览器会节流 rAF）
