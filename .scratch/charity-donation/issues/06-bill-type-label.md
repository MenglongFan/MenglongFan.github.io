# 06: 账单里的捐赠类型标签

**What to build:** 账单——双击奖池余额弹出来的那块流水面板——里，捐赠要显示成「慈善捐赠」而不是「支取」，并且和罚金、支取在视觉上区分得开，扫一眼就知道每笔的性质。这一票同时修掉一个现成的 bug：账单原来的判断是「不是罚金就是支取」，现在只有两种类型所以恰好成立，一旦引入捐赠，**一笔入账会被标成出账**。账本把进项标成出项，是致命的。

**Blocked by:** 04

**Status:** ready-for-agent

- [ ] 三种类型的标签各自分支：罚金 →「罚金入账」、捐赠 →「慈善捐赠」、其余 →「支取」
- [ ] 捐赠金额显示为正数入账，不显示负号
- [ ] 三种类型的徽标在颜色或样式上互相区分（罚金与捐赠都是入账，同色就分不出「交钱」和「掏钱」）
- [ ] 捐赠流水显示操作后余额，能自己把账对上
- [ ] 没有备注的捐赠不显示一个空的备注位（后端留空时会落一个固定默认串，别把它当备注重复显示）
- [ ] 账单的开关动画与滚动锁定行为不因为多了捐赠类型而变化
- [ ] 账单里捐赠与罚金、支取的排序仍按时间倒序，不因类型而分组
