# 03: 捐赠称谓按累计额分档

**What to build:** 累计捐赠额跨过门槛时，捐赠人的名字旁边出现对应的**捐赠称谓**：5 元 → 解囊相助、20 元 → 仗义疏财、50 元 → 乐善好施、100 元 → 义薄云天。每人只显示当前最高档的一个——一行名字旁边挂四个名号会挤爆窄屏，而且称谓的语义是「你现在是什么人」，不是「你拿过哪些奖」。门槛设在一次末位罚金（15 元）以下，保证「捐了就有名分」。称谓由后端按累计额派生，前端只渲染拿到的字符串。

**Blocked by:** 01（切片助手）、02（榜上要有位置显示）

**Status:** ready-for-agent

- [ ] 称谓由「累计额 → 称谓」的纯函数计算，阈值与字符串只存在一份，不落库
- [ ] `0 / 4.99 / 5 / 19.99 / 20 / 49.99 / 50 / 99.99 / 100 / 1000` 各返回正确档位；判据是 `>=`，恰好 5.00 即达标
- [ ] 负值不崩；超大额返回最高档
- [ ] 边界用例有自动化测试覆盖，且测试从源码切出真实函数执行（不是测试里重写的一份）
- [ ] 慈善榜上每人只显示一个称谓胶囊，且是当前最高档
- [ ] 累计额掉到门槛以下时返回空称谓，前端不渲染胶囊（不留一个空壳）
- [ ] 前端不重复一份阈值表
