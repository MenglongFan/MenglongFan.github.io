# 02: 慈善榜只读展示

**What to build:** 打开奖池页就能看到一块独立的「慈善奖金」区域，显示累计捐赠总额与捐赠人名单（按累计额从高到低）。池子里有捐赠时，总余额下方多出一行「其中慈善捐赠 N 元」，让房主分得清这堆钱里有多少是捐的；一笔捐赠都没有时显示一句空态文案，并且**不出现**那一行拆分行。整块内容访客无需密码即可查看——捐赠是要被感谢的，藏起来等于白捐。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 奖池汇总响应包含累计捐赠额与捐赠人列表，每项含玩家 id、姓名、头像、累计额、笔数，按累计额降序
- [ ] 奖池页出现「慈善奖金」区块，与「贡献榜」并列但独立成榜
- [ ] 累计捐赠额 > 0 时，余额数字下方显示「其中慈善捐赠 N 元」；为 0 时不渲染这一行
- [ ] 无任何捐赠时区块显示空态文案，页面不报错、不白屏
- [ ] 后端未返回这两个字段时前端按 0 处理，不白屏（部署不是原子的，版本错开的窗口真实存在）
- [ ] 「贡献榜」的内容与改动前完全一致，仍然只统计罚金
- [ ] 不输入房主密码即可查看该区块
- [ ] 累计捐赠额累加后收口到分，不出现浮点尾数
