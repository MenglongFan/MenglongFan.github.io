# ADR 0002: 积分公式 — 最高分 = 死亡人数 + 1

**状态**: 已接受
**日期**: 2026-09-17

## 背景

国战积分系统需要一套积分规则，基于玩家在对局中的存活/淘汰顺序计算得分。

可选方案：
- **(A) 固定最高分 N**：N 人局冠军得 N 分，按淘汰顺序递减至 1。同排名共存者都得 N 分。总发放分数会因同排名膨胀。
- **(B) 最高分 N，跳号递减**：同排名者都得最高分，后面的人按出局顺序跳号排列。总分会膨胀但排名编号不断裂。
- **(C) 最高分 = 死亡人数 + 1（用户提出）**：存活者均得（D+1）分，死者按淘汰顺序从 D 递减至 1。总发放分数有上界，不会因存活人数多而膨胀。

## 决策

选择 **(C) 最高分 = 死亡人数 + 1**。

## 理由

1. **总分不膨胀**：存活者数量不影响最高分，只有死亡人数决定。5 人死亡 + 3 人存活 = 最高 6 分；8 人死亡 + 0 人存活 = 最高 9 分。奖励"淘汰更多对手"而非"存活人数多"。
2. **用户直觉**：用户（房主）提出的规则，符合其对国战节奏的理解——杀的人越多这局价值越高。
3. **简单可算**：录入时只需排淘汰顺序并标记存活者，系统自动算分，无需复杂分配逻辑。

## 后果

- 同一局总发放分数 = 存活人数 × (D+1) + (D + (D-1) + ... + 1) = S×(D+1) + D(D+1)/2，其中 S = 存活人数，D = 死亡人数。
- 赛季排名只看总积分，绝对分数的尺度不影响相对排名。
- 如果未来想改为其他积分公式，需要重新计算所有历史对局的分数。
