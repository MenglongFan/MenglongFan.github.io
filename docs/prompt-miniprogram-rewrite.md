# 国战积分 · 线下国战积分与奖池记账小程序

原生微信小程序 + 微信云开发从零实现，前后端都在微信生态内：前端 wxml/wxss/js/json，后端仅云函数 + 云数据库。禁用外部 HTTP 接口、web-view 与现有 Worker/D1。业务逻辑与鉴权收口云函数，集合权限「仅管理端可读写」，前端不直接读写库。金额用整数分存储运算，禁用浮点。

## 页面
排名榜是全屏主视图，其余功能由右下角浮动按钮开弹窗，同时只开一个，关闭后主视图刷新。
1 积分榜：总积分降序，头像/姓名/积分/局数；点击展开逐局明细；同分同名次；无赛季或无对局显示空态。
2 录入：勾选到场 5–10 人 → 拖拽淘汰顺序（上=最后存活，下=最先淘汰）→ 标记顶部 1–N 名存活者 → 指定至多 1 名首亮玩家 → 按键累加各人申报击杀数 → 实时分数预览 → 提交。
3 花名册：可新增、可改名，禁止删除。种子 7 人：樊梦龙、齐济、赵振东、李晓阳、范昊宇、肇淘胜、祝振军。
4 赛季：新建/暂存/恢复/结束/查看历史排名。三态 active/paused/ended，同时最多一个 active；ended 不可逆且锁数据；暂存不结算罚金、可恢复。
5 奖池：总余额、贡献榜（仅罚金）、慈善榜（仅捐赠）、流水（时间/类型/金额/说明/余额）、支取。

## 集合
players、seasons(status,prizeCalculated)、seasonPlayers、matches(firstRevealPlayerId)、matchResults(rank,isSurvivor,score,killCount)、poolTransactions(type,amountCents,balanceCents)。rank 是录入拖拽顺序、非榜面名次，名次由接口推导。

## 算法（必须精确）
积分：死亡人数 D = 总人数 − 存活人数；存活者各得 D+1，死者按淘汰顺序从 D 递减到 1；首亮玩家额外 +1；每人按申报击杀数每人头 +1。加分并入 score。一局所有人击杀数合计 ≤ D（全场额度）。历史对局不重算。
罚金：结束时按总积分升序取末三档 15/10/5 元；同分即同排名，并列组平摊其占据档位金额之和，并列可跨末三位边界（倒数第三并列时线内外两人共分 5 元）；总额恒 30 元。计算与流水写入走数据库事务，之后锁定。
奖池：罚金与自愿捐赠进同一池、只按类型区分账目，支取记负数流水。贡献榜只统计罚金，不含捐赠。捐赠终身累计、不绑定赛季、必须绑定玩家、不匿名；称谓按累计额派生、不落库：5/20/50/100 元 → 解囊相助/仗义疏财/乐善好施/义薄云天，只显示最高档一个，删记录掉档时自动回退。

## 鉴权与合规
房主密码是共享口令、非账号系统：存云函数环境变量，写操作（录入/花名册/赛季/捐赠/支取）校验，查看类接口全开放。不做注册登录、微信支付或在线收款——罚金与捐赠均为线下现金、系统只记账；文案禁出现充值、提现、支付。名称用「国战积分」，勿出现「三国杀」。

## 视觉与边界
深色国风水墨、墨底米白字、朱砂红强调，rpx 适配，竖屏不横向滚动。不记录阵营、武将牌、击杀对象；不做实时推送、导出、图表。交付可编译完整工程：app.json 页面注册、project.config.json、sitemap.json、云函数目录、种子数据。
